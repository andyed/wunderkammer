# Use statement (sitting jx-1017-t5)

Written once for this product and passed verbatim to every sitting.

> An open-source browser component that lets a language model show a person a
> large collection of images. The model writes the collection as a JSON
> document; the person pans, zooms, filters by facets, groups items, compares
> groups side by side, and opens any item. The model can also attach claims
> about a comparison, each pointing at the exact items behind it, and the
> person's current selection can be handed back to the model as exact
> evidence. It runs from static files with no server, and also as a local
> workspace over a person's own clippings, image archives and music artwork.

Constraints on the name, fixed for this sitting:

- It is the npm package name, the GitHub repository name, and the prefix of
  three JSON format identifiers: `<name>.collection`, `<name>.observations`,
  `<name>.export`. Lowercase ASCII letters only works in all three.
- Language models and people type it into prompts and code. Spelling from
  hearing matters.
